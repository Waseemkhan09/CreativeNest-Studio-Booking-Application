
# 🎬 CreativeNest – Studio Booking Application

CreativeNest is a full-stack web application built to empower photographers, videographers, and content creators by offering affordable and easy access to professional studios and high-end equipment. With a focus on usability, sustainability, and community, CreativeNest lowers the entry barrier for creative professionals and enthusiasts alike.

## 📖 About the Project

CreativeNest addresses the financial challenges faced by emerging creators in accessing premium gear and studios. It provides:

- An intuitive booking platform for renting professional studios.
- High-end photography and videography equipment.
- A community-driven experience with ratings and feedback.
- A sustainable, shared-use model to reduce environmental impact.

🎯 **Goal:** Democratize access to creative resources while fostering an inclusive and eco-conscious content creation community.

---

## ✨ Key Features

- 🔍 **Search & Filter**: Locate studios and equipment tailored to your project needs.
- 📅 **Real-Time Availability**: See up-to-date availability and book instantly.
- 🧾 **Booking Management**: View, modify, or cancel bookings effortlessly.
- 🗣️ **User Reviews**: Share and read rental experiences to improve service trust.
- 💬 **Customer Support**: Live chat and email support for seamless user experience.
- 🌐 **Responsive Design**: Works seamlessly across devices.

## 🏗️ System Architecture

```
Frontend (React)
     ↓
Express.js Server (Node.js)
     ↓
MongoDB (NoSQL Database)
```

- RESTful APIs handle booking, user, and equipment data.
- Scalable backend with modular structure and reusable components.

## 🔄 How It Works

1. **User Registration/Login**  
2. **Browse Studios and Equipment**
3. **Select Dates & View Availability**
4. **Make Booking**
5. **Receive Confirmation and Manage Bookings**
